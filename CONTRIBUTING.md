# Разработка

## Локальная установка

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -e .
```

Добавляйте в пакет только общие механизмы интеграции. Настройки, sys_id и
бизнес-правила конкретной инсталляции должны оставаться в приложении-клиенте
или передаваться явно. Не добавляйте реальные адреса с закрытым доступом,
учётные данные, выгрузки или данные заявок.

## Проверка сборки

```bash
python -m pip wheel . --no-deps --wheel-dir dist
```

Pull request должен сохранять совместимость публичного API либо документировать
изменение. Новые зависимости добавляйте только при необходимости.
